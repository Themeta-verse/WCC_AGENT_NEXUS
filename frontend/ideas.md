# NEXUS Independent Command Center — Design Directions

## Three possible directions

### 1. Signal Archive
**Very Brief Intro:** A calm editorial control surface inspired by research archives and mission logs. It makes evidence, provenance, and uncertainty feel legible rather than dramatic.
**Probability:** 0.07

### 2. Meridian Operations Desk
**Very Brief Intro:** A disciplined technical workspace built from blueprint lines, ink-black typography, and instrument-panel density. It frames NEXUS as a serious operating product instead of a chat interface.
**Probability:** 0.03

### 3. Field Intelligence Ledger
**Very Brief Intro:** A tactile, light-mode planning system with annotated records and physical-document cues. It emphasizes continuity and deliberate decision-making.
**Probability:** 0.09

## Chosen direction: Meridian Operations Desk

### Design Movement
Contemporary technical editorialism with restrained aerospace-instrument influences. The interface should feel like a trustworthy, independent control product: structured, quiet, and exact.

### Core Principles
1. Evidence is visually primary: source, state, verification, and scope should read before ornament.
2. The interface is asymmetric and operational, using a fixed intelligence rail plus an adaptive mission workspace.
3. Every color communicates status or hierarchy; no decorative neon, generic gradients, or dashboard-card clutter.
4. Boundaries must be visible: simulated, observed, verified, prepared, and unavailable are distinct states.

### Color Philosophy
Use warm graphite and paper-white as the durable base, with a single oxidized teal as NEXUS’s ownable signal color. Amber denotes review/attention; muted rose indicates blocked or unavailable actions. Color is sparse so verification states remain meaningful.

### Layout Paradigm
An offset operations desk: a narrow vertical identity/evidence rail on the left, a broad central mission canvas, and a slim inspection pane on wide screens. On mobile, the rail collapses into a compact command strip while evidence remains in reading order.

### Signature Elements
1. Thin coordinate rules and timestamp-style labels that make each view feel sourced.
2. A circular NEXUS aperture mark, used as a live-but-not-alive system indicator.
3. Evidence stamps with square corners, monospace metadata, and explicit reality-state labels.

### Interaction Philosophy
Interactions should clarify state rather than decorate it. Controls reveal capability limits, request progress, and evidence provenance. Destructive actions never appear as active primary actions.

### Animation
Use only short opacity and transform transitions for panel updates, command submission, and status changes. Respect reduced-motion preferences. No looping motion, glow pulses, or gratuitous loading effects.

### Typography System
Use **Space Grotesk** for display hierarchy and **IBM Plex Mono** for sources, status, and operational metadata. Headings are compact and assertive; body copy is calm and spacious. Avoid Inter.

### Brand Essence
**NEXUS is a verifiable mission operating system for teams that need evidence before action.**

Personality: exacting, composed, accountable.

### Brand Voice
Headlines are direct and evidence-first; CTAs state the next controlled action; microcopy names limits plainly.

Example lines:
- “Run the smallest evidence set that can change the decision.”
- “Prepared for review. No external action has been authorized.”

### Wordmark & Logo
The wordmark is a custom spaced NEXUS label paired with an aperture-like graphic mark: three offset arcs resolving toward a central point. The mark must work without text.
